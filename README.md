# visite-luxemburgo

Landing page moderne en français sur le Luxembourg avec animations et panneaux superposés.

## Contenu
- Home animée avec boutons **Info** et **Culture**.
- Panel **Info**: localisation, drapeau, langues et plat typique (Bouneschlupp).
- Panel **Culture**: Louis Pilot, Schueberfouer et costume traditionnel Eisleker Tracht.

## Démarrage rapide
Ouvrez `index.html` dans votre navigateur.
